# ParticleStuff
This is an open-source Sandbox particle simulation physics engine under the MIT License

# IMPORTANT:
- Unzip the folder first before running the program.
- Please do not change any folder names nor any asset names; doing so would break the assets directory part of the program.

## Features:
- 4 particles so far! (Water, Sand, Soil, Mud)
- Working physics engine
- First chemical-ish (Hydrolisis) reaction (Try finding it out for yourself)
